# Publication Clearance

No public claim, benchmark, performance comparison, raw Jev output, or public download is cleared by repository implementation alone.

## Claims That Remain Blocked

- General autonomous Mac control.
- Guaranteed safety, interruption, exactly-once execution, or accuracy.
- One-second end-to-end performance.
- All-local processing merely because audio is not sent to Jev.
- Better performance than another system without a controlled comparison.
- Generated content when no content-generation source exists.
- Public benchmark or performance information without applicable agreement clearance.

## Required Clearance Before Any External Claim

- Applicable TypeSafe/Jev agreement identified and reviewed.
- Direct-client, private-prototype, data handling, provider retention, and publication conditions recorded.
- Evidence scope, baseline, sample size, percentile, warm/cold conditions, exclusions, and failures defined.
- All required target-Mac and fixture gates passed.
- Security and privacy review completed.
- Daniel explicitly approves the exact wording and destination.

The current status is `not cleared`.
